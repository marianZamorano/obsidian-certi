# Certi — Bóveda de Obsidian

Bóveda personal de notas versionada con git.

## Uso

1. Abre esta carpeta en Obsidian como bóveda.
2. Sincroniza con GitHub con el plugin **Obsidian Git** o manualmente:
   ```bash
   git add -A && git commit -m "notas: actualización" && git push
   ```

Ver [CLAUDE.md](CLAUDE.md) para la estructura de carpetas y convenciones.
