# Generador de costos

Variable, como el nivel de actividad o volumen, que influye de manera causal en los costos durante un periodo dado ([[Contabilidad de costos - Horngren.pdf#page=54|p. 32]]).

## Explicación

- Ejemplos: unidades producidas para materiales directos; número de configuraciones de máquinas para costos de configuración ([[Contabilidad de costos - Horngren.pdf#page=54|p. 32]]).
- Criterios para elegirlo: viabilidad económica, bondad del ajuste y significado de la variable independiente ([[Contabilidad de costos - Horngren.pdf#page=388|p. 366]]).
- Usar generadores de costos como base de aplicación es una forma de mejorar un sistema de costeo ([[Contabilidad de costos - Horngren.pdf#page=185|p. 163]]).
